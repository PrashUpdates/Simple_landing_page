# 🌐 Simple Landing Page

A clean and responsive landing page built using only HTML and CSS. This project includes a sticky navigation bar, smooth scrolling, responsive layout, and a minimal footer with social links. Created from scratch to practice modern layout techniques and responsive web design.

## 🪼 Features

- Responsive Navigation Bar
- Sticky Header
- Smooth Scrolling
- Responsive Layout
- Minimal Footer
- Hover Effects
- CSS Variables
- Mobile Friendly

## 🛠️ Technologies Used

- HTML5
- CSS3
